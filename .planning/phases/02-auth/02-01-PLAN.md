    **Step 1: Auth Router** (app/api/auth.py)
    Create APIRouter with `tags=["auth"]`.

    Endpoint 1: `POST /telegram`
    - Request body: TelegramAuthRequest
    - Convert request to dict (exclude None values for HMAC)
    - Call verify_telegram_auth(data_dict, settings.tg_bot_token) — if False, raise HTTPException 401 "Invalid Telegram authentication data"
    - Call upsert_user(session, tg_data) to create/update user
    - Call create_access_token(user.id, user.id) — user.id IS telegram_id
    - Call create_refresh_token(user.id) — returns (token_str, jti)
    - Save RefreshToken to DB: insert with user_id, token, jti, expires_at (now + refresh_token_expire_days)
    - await session.commit()
    - Return AuthResponse with access_token, refresh_token, token_type="bearer", expires_in=settings.access_token_expire_minutes * 60, user=UserInfo(id=user.id, username=user.username)

    Endpoint 2: `POST /refresh`
    - Request body: RefreshRequest
    - decode_token(request.refresh_token) — catch InvalidTokenError -> 401
    - Check payload["type"] == "refresh" — else 401
    - Look up RefreshToken in DB by jti: `select(RefreshToken).where(RefreshToken.jti == payload["jti"])`
    - If not found -> 401 "Refresh token not found or revoked"
    - Create new access_token via create_access_token(int(payload["sub"]), int(payload["sub"]))
    - Return RefreshResponse with access_token, token_type="bearer", expires_in=settings.access_token_expire_minutes * 60

    Endpoint 3: `GET /me`
    - Dependency: `current_user: User = Depends(get_current_user)`
    - Return UserInfo(id=current_user.id, username=current_user.username)
