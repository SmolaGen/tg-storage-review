**app/state.py** — TelegramPool singleton:

Создать класс `TelegramPool` с атрибутами:
- `_clients: dict[UUID, TelegramClient]` (пустой dict в __init__)
- `_semaphores: dict[UUID, asyncio.Semaphore]` (пустой dict в __init__)

Методы:
1. `async def get_or_create(self, worker_id: UUID, bot_token: str, session_string: str | None, api_id: int, api_hash: str) -> TelegramClient` — если worker_id в _clients, вернуть существующий. Иначе: `StringSession(session_string) if session_string else StringSession()`, создать `TelegramClient(session, api_id, api_hash)`. Если session_string есть — `await client.connect()` (НЕ start). Если нет session_string — `await client.start(bot_token=bot_token)`. Сохранить в `_clients[worker_id]`.
2. `def semaphore(self, worker_id: UUID) -> asyncio.Semaphore` — lazy создание `asyncio.Semaphore(3)` per worker_id.
3. `async def remove(self, worker_id: UUID) -> None` — pop из _clients и _semaphores, если client есть — `await client.disconnect()`.
4. `async def shutdown(self) -> None` — disconnect все клиенты, очистить оба dict.

Module-level синглтон: `telegram_pool = TelegramPool()`

Использовать `import logging; logger = logging.getLogger(__name__)` для логирования (НЕ print, НЕ console.log). Логировать: `logger.info("TelegramPool: connecting worker %s", worker_id)` при connect и `logger.info("TelegramPool: disconnected worker %s", worker_id)` при disconnect.

**app/services/storage.py** — validate_and_register_worker:

```python
async def validate_and_register_worker(
    bot_token: str,
    chat_id: int,
    api_id: int,
    api_hash: str,
) -> str:
```

Логика:
1. `session = StringSession()`
2. `client = TelegramClient(session, api_id, api_hash)`
3. try блок: `await client.start(bot_token=bot_token)` → `me = await client.get_me()` → if me is None: raise ValueError("Bot not found") → `await client.get_entity(chat_id)` → `return session.save()`
4. except блоки (в указанном порядке):
   - `(AccessTokenInvalidError, AccessTokenExpiredError)` → `raise ValueError("Invalid or expired bot_token")`
   - `ChannelPrivateError` → `raise ValueError("Bot does not have access to the channel. Add bot as admin.")`
   - `ChatAdminRequiredError` → `raise ValueError("Bot must be an admin in the channel.")`
   - `FloodWaitError as e` → `raise ValueError(f"Telegram rate limit: retry after {e.seconds}s")`
   - `UserDeactivatedBanError` → `raise ValueError("Bot account is banned")`
   - `Exception as e` → `raise ValueError(f"Telegram validation failed: {e}")`
5. finally: `await client.disconnect()`
