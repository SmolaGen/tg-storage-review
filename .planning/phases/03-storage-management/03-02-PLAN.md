**app/services/storage.py** — добавить CRUD-функции (дописать к уже существующему validate_and_register_worker):

1. `async def create_storage(session: AsyncSession, user_id: int, data: StorageCreate) -> Storage`:
   - `storage = Storage(user_id=user_id, name=data.name, chat_id=data.chat_id)`
   - `session.add(storage)` → `await session.commit()` → `await session.refresh(storage)` → return storage

2. `async def list_user_storages(session: AsyncSession, user_id: int) -> list[dict]`:
   - SQL: `select(Storage, func.count(StorageWorker.id).label("worker_count")).outerjoin(StorageWorker, StorageWorker.storage_id == Storage.id).where(Storage.user_id == user_id).group_by(Storage.id)`
   - Вернуть list[dict] с полями: id, name, chat_id, created_at, worker_count
   - Формирование dict через spread (иммутабельность): `{**{attr: getattr(storage, attr) for attr in [...]}, "worker_count": wc}`

3. `async def get_storage_by_id_and_owner(session: AsyncSession, storage_id: UUID, user_id: int) -> Storage | None`:
   - `select(Storage).where(Storage.id == storage_id, Storage.user_id == user_id)` → scalars().first()
   - Возвращает None если не найдено (для 404 в роутере) — IDOR protection

4. `async def add_worker(session: AsyncSession, storage: Storage, bot_token: str, api_id: int, api_hash: str) -> StorageWorker`:
   - Вызвать `session_string = await validate_and_register_worker(bot_token, storage.chat_id, api_id, api_hash)`
   - `worker = StorageWorker(storage_id=storage.id, bot_token=bot_token, session_string=session_string)`
   - `session.add(worker)` → `await session.commit()` → `await session.refresh(worker)`
   - После commit: `await telegram_pool.get_or_create(worker.id, bot_token, session_string, api_id, api_hash)` — зарегистрировать в пуле
   - return worker

5. `async def list_workers(session: AsyncSession, storage_id: UUID) -> list[StorageWorker]`:
   - `select(StorageWorker).where(StorageWorker.storage_id == storage_id)` → scalars().all()

3. `POST /{storage_id}/workers` → 201:
   ```python
   @router.post("/{storage_id}/workers", response_model=WorkerResponse, status_code=status.HTTP_201_CREATED)
   async def add_worker_endpoint(
       storage_id: UUID,
       data: WorkerCreate,
       current_user: User = Depends(get_current_user),
       session: AsyncSession = Depends(get_session),
   ):
       storage = await get_storage_by_id_and_owner(session, storage_id, current_user.id)
       if storage is None:
           raise HTTPException(status_code=status.HTTP_404_NOT_FOUND, detail="Storage not found")
       try:
           worker = await add_worker(session, storage, data.bot_token, settings.tg_api_id, settings.tg_api_hash)
       except ValueError as e:
           raise HTTPException(status_code=status.HTTP_400_BAD_REQUEST, detail=str(e))
       return worker
   ```

4. `GET /{storage_id}/workers` → 200:
   ```python
   @router.get("/{storage_id}/workers", response_model=list[WorkerResponse])
   async def list_workers_endpoint(
       storage_id: UUID,
       current_user: User = Depends(get_current_user),
       session: AsyncSession = Depends(get_session),
   ):
       storage = await get_storage_by_id_and_owner(session, storage_id, current_user.id)
       if storage is None:
           raise HTTPException(status_code=status.HTTP_404_NOT_FOUND, detail="Storage not found")
       return await list_workers(session, storage.id)
   ```
