    **app/main.py:**
    ```python
    import logging
    from contextlib import asynccontextmanager
    from fastapi import FastAPI
    from app.database import engine
    from app.api.health import router as health_router

    logger = logging.getLogger(__name__)

    @asynccontextmanager
    async def lifespan(app: FastAPI):
        logger.info("Starting up: DB engine ready")
        yield
        await engine.dispose()
        logger.info("Shutdown: DB engine disposed")

    app = FastAPI(title="tg-storage", lifespan=lifespan)
    app.include_router(health_router)
    ```

    НЕ использовать `@app.on_event("startup")` — deprecated.
    НЕ использовать `console.log` — только `logging.getLogger(__name__)`.

    **Dockerfile:**
    ```dockerfile
    FROM python:3.12-slim

    WORKDIR /app

    # Установка зависимостей отдельным слоем для кеширования
    COPY requirements.txt .
    RUN pip install --no-cache-dir -r requirements.txt

    # Копирование кода
    COPY . .

    # Запуск: alembic upgrade head + uvicorn
    CMD ["sh", "-c", "alembic upgrade head && uvicorn app.main:app --host 0.0.0.0 --port 8000"]
    ```

    Использовать `python:3.12-slim` (не alpine — cryptg требует C компилятор, slim уже содержит gcc headers).
    CMD запускает `alembic upgrade head` перед uvicorn — миграции применяются автоматически при каждом старте (идемпотентно).

    **docker-compose.yml:**
    ```yaml
    services:
      db:
        image: postgres:17-alpine
        environment:
          POSTGRES_USER: tgstorage
          POSTGRES_PASSWORD: tgstorage
          POSTGRES_DB: tgstorage
        ports:
          - "5432:5432"
        volumes:
          - pgdata:/var/lib/postgresql/data
        healthcheck:
          test: ["CMD-SHELL", "pg_isready -U tgstorage"]
          interval: 5s
          timeout: 5s
          retries: 5

      api:
        build: .
        ports:
          - "8000:8000"
        env_file:
          - .env
        depends_on:
          db:
            condition: service_healthy
        volumes:
          - .:/app

    volumes:
      pgdata:
    ```

    КРИТИЧНО: `depends_on` с `condition: service_healthy` — без этого FastAPI стартует до готовности PostgreSQL (Pitfall #4).
    Volume `.:/app` для hot reload при локальной разработке.
    `pgdata` named volume — данные PostgreSQL переживают `docker-compose down`.
